# MegaSuite ⚡

**MegaSuite** is the ultimate all-in-one Geometry Dash mod for the **Geode Mod Loader**, engineered in the sleek, dark, high-performance style of **MegaHack**.

Instead of cluttering your Geode installation with dozens of separate mods, **MegaSuite** merges the essential functionality of **QOLMod**, **DVD Mode**, comprehensive community **Bugfixes**, and developer **APIs** into a single cohesive interface.

---

## 🌟 Key Features

### 🎮 1. QOLMod & Gameplay Hacks
- **Speedhack:** Precise, smooth game speed acceleration and deceleration with optional audio pitch synchronization.
- **StartPos Switcher:** Easily navigate across start positions in levels with on-screen triggers or hotkeys.
- **Show Hitboxes:** Accurate object and hazard boundaries in practice mode and gameplay.
- **Practice Music Sync:** Unlocks the actual level soundtrack while placing practice checkpoints.
- **Instant Respawn:** Eradicates death delays for seamless attempt grinding.
- **Noclip Testing:** Hazard contact bypass for practice exploration and level verification.

### 💿 2. DVD Mode (Integrated Screensaver Physics)
- **Bouncing Dialogs:** Popups, pause menus, and alert layers bounce diagonally around your screen edges like the iconic DVD screensaver!
- **Collision Reflection:** Precise mathematical vector bounces off viewport boundaries.
- **Speed & Weight Controls:** Customizable bounce speeds with heavier popups moving with authentic mass.
- **Trigger Filtering:** Option to leave level editor trigger setup dialogs unaffected.

### 🛠️ 3. Comprehensive Bugfixes Suite
- **Practice Music Sync Pulse Fix:** Eliminates pulsing object glitches on main level songs.
- **Player 2 Wave Trail Fix:** Fixes dual-wave trail dropouts and glitches when crossing dual portals.
- **StartPos Mirror Mode Fix:** Respects mirror portal inversion when spawning from test StartPositions.
- **Mini Swing Icon Fix:** Resolves bug causing mini swing to render default cube icon.
- **Dash Orb Particle Offset Fix:** Aligns dash ring activation particle bursts.
- **Show Trigger Wave Particle Fix:** Cleans up thruster smoke artifacts when showing wave icons.

### 🔌 4. Developer & API Hub
- **Level ID API:** Instant metadata and ID access for online and custom levels.
- **Node IDs Inspector:** Recursive scene graph logging and element lookup.
- **Unified Persistence API:** Fast, crash-resistant cross-mod key-value storage.

---

## ⌨️ Controls & Hotkeys

- Press <kbd>Tab</kbd> anywhere in-game or in the menus to open or close the **MegaSuite** window.
- Click the green **MegaSuite** icon on the bottom navigation bar of the Main Menu.
- Drag the top bar of the window to reposition it anywhere on your screen.
