# MegaSuite Changelog

## [1.0.0] - Initial Unified Release
- **Unified Architecture:** Combined QOLMod, DVD Mode, community bugfixes, and developer APIs into a single Geode mod.
- **MegaHack Styled UI:** Built a dedicated dark acrylic floating window featuring neon green accents, tabbed navigation, smooth animations, and draggable header bar.
- **QOL Suite:** Integrated Speedhack, StartPos Switcher, Hitbox visualizer, Practice Music Sync, Instant Respawn, and Noclip.
- **DVD Mode:** Complete 2D vector reflection popup bouncing physics with mass scaling and editor dialog filters.
- **Bugfixes Included:**
  - Practice music sync object pulsing fix
  - Player 2 dual wave trail render fix
  - StartPos mirror portal orientation fix
  - Mini swing custom icon fix
  - Dash orb particle alignment fix
  - Show trigger wave trail particle fix
- **APIs:** Level ID query API, recursive Node IDs inspector, and unified cross-mod persistence storage.
